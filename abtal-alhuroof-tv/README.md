# أكاديمية الأبطال — ألعاب تأسيس أول ابتدائي 🎮📚

تطبيق Android TV تعليمي عربي مستقل يعمل دون إنترنت، مصمم للريموت ولأجهزة أندرويد القديمة (Android 4.4.4 / API 19) والجديدة. يضم 22 نمط لعبة: 6 عربية، 6 رياضيات، 6 إنجليزية، و4 مغامرات، مع أسئلة عشوائية وجوائز افتراضية محلية.

## المزايا
- تحكم D-Pad (↑ ↓ ← →)، زر OK/Enter، رجوع، واختيار بالفأرة أو اللمس.
- ملفات HTML/CSS/JavaScript بلا مكتبات أو API خارجي.
- نجوم وعملات وصندوق هدايا افتراضية بعد كل 5 أسئلة وإنجازات.
- الأصوات عبر Android TextToSpeech في حال وجود حزمة صوت اللغة على الجهاز.
- حفظ تلقائي للتقدم في localStorage، دون حسابات أو جمع بيانات.
- سؤال بحروف كبيرة ورسوم وأيقونات وخيارات بألوان واضحة على التلفزيون.

## بناء APK
1. افتح المشروع باستخدام Android Studio (JDK 17، Android SDK 35، Android Gradle Plugin 8.6.1)، أو نفّذ `gradle :app:assembleDebug` في مسار المشروع.
2. سيتوفر الملف في `app/build/outputs/apk/debug/app-debug.apk`.
3. فعّل تثبيت التطبيقات من مصادر أخرى على التلفاز ثم ثبت ملف APK.

**مهم:** Debug APK مُوقّع بمفتاح تطوير يختلف بين بيئات البناء؛ للحصول على تحديثات تثبت فوق النسخة القديمة، استخدم مفتاح إصدار ثابت وآمن. التوافق مع طراز التلفزيون الحقيقي، تشغيل TTS، وأداء WebView يحتاج تجربة على الجهاز.

## التحكم في الكمبيوتر
الأسهم، Enter، Escape. افتح `app/src/main/assets/index.html` مباشرة للمعاينة.

## بيانات البرنامج
- الحزمة `sa.youef.abtalalhuroof`
- الحد الأدنى `API 19 / Android 4.4`
- لا يحتوي على مكونات native ABI، لذلك لا يتطلب ملفات ARMv7 أو ARM64 مخصصة.
