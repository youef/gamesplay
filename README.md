# فواز وزياد – اليوم الوطني السعودي 96 🇸🇦

لعبة ثلاثية الأبعاد (Three.js) تشتغل في المتصفح، شاشة مقسومة للاعبين، عالم مفتوح لمدينة عرعر
مع **الواجهة الشمالية**: مطار فيه طائرة تقلع وتهبط، وحديقة فيها حلبة سباق، و11 قطعة عقار للشراء
والتطوير والبيع، ومحفظتين مستقلتين تبدأ كل واحدة بـ **10,000,000**.

## بنية المشروع (مفصولة لتسهيل التطوير)

| الملف | الدور |
|---|---|
| `index.html` | هيكل الصفحة + الأزرار + الواجهة البصرية (HTML/CSS فقط) |
| `js/core.js` | أدوات عامة، الحالة المحفوظة، الصوت، العارض، الرسم، التصادم، شبكة المدينة |
| `js/wallet.js` | المحفظتان: `gain` يوزّع بالتساوي، `gainTo` لمالك العقار، `pay`/`spend` |
| `js/vehicles.js` | سيارات اللاعبين والحركة والتفحيط ومحطات الوقود والتصادم |
| `js/characters.js` | الشخصيات: فواز وزياد بأزياء تقليدية + أطفال وراء الكرة |
| `js/decor.js` | كتالوج الديكور: شجرة/نخلة/بسطة/حديقة/نافورة... مع وضع وإزالة |
| `js/buildings.js` | المباني داخل حارات المدينة وإيجارها |
| `js/world.js` | بناء المدينة: الحارات، البيوت، المباني، المواقف، الديكور الأساسي |
| `js/north.js` | الواجهة الشمالية: المطار، الطائرة، الحديقة، حلبة السباق وحواجزها |
| `js/items.js` | العناصر المتنقلة: عملات، هدايا، أعلام وهمية، وهمسة المهمة |
| `js/player.js` | إدخال اللاعبين، الكاميرا (زاوية/تقريب/ميلان)، المهام |
| `js/race.js` | سباق التحدي: عد تنازلي مجمّد، نقاط التفاف، حكم فائز، جوائز |
| `js/properties.js` | القطع العقارية: شراء، تطوير، دخل لحظي، بيع |
| `js/minimap.js` | الخريطة المصغرة المرسومة بالكامل (المدينة + الواجهة الشمالية) |
| `js/ui.js` | قوائم اللعبة: المتجر، البناء، الديكور، العقارات، المحفظة، السباق، الإعدادات |
| `js/game.js` | حلقة اللعب، بدء اللعب، الحفظ/التحميل، الرسوم المتحركة |
| `tests.html` | اختبارات آلية (36 اختبارًا) — افتحه قبل أي تعديل وتأكد 100% |

كل ملف وحدة مستقل (IIFE) وتتشارك عبر `window.ND`، وترتيب التحميل مكتوب في `index.html`.

## التحكم

### كيبورد
| | حركة | ركوب/نزول | تفحيط | الكاميرا |
|---|---|---|---|---|
| **فواز (1)** | `W A S D` | `E` | `Space` | تدوير `Z`/`X` — تقريب `R`/`F` — ميلان `T`/`G` |
| **زياد (2)** | `↑ ↓ ← →` | `Enter` | `Shift يمين` | تدوير `,`/`.` — تقريب `PageUp`/`PageDown` — ميلان `I`/`K` |

- أزرار الكاميرا أسفل كل شاشة تعمل باللمس والماوس.
- زر ⚙ في الأعلى يفتح القوائم (المتجر، البناء، الديكور، العقارات، المحفظة، السباق، الإعدادات).

### آيباد/جوال
عصا يسار الشاشة + زر ركوب/نزول + زر تفحيط لكل لاعب.

## أبرز المميزات
- **محفظتان مستقلتان**: دخل المباني والمهام يُوزَّع بالتساوي، ودخل العقار يذهب لمالكه وحده.
- **سباق التحدي**: حلبة دائرية شمال الحديقة، عد تنازلي يجمّد السيارات، 6 نقاط تفاف، الفائز 600,000
  والخاسر 200,000، ومع لاعب واحد يواجه خصمًا ذكيًا. لا يبدأ تلقائيًا أثناء القيادة.
- **11 قطعة عقارية** بستة أنواع (محل، بقالة، مطعم، محطة وقود، فندق، برج) بثلاث مستويات تطوير.
- **محطة وقود** يكبُر صرحها كلما رُقّية، وتبيع الوقود بسعر أرخص لمالكها.
- **مطار**: مدرج، صالة، برج مراقبة، وطائرة تكمل دورة إقلاع → ارتفاع → تحليق → هبوط.
- **المدينة**: سيارات ذكية تحترم قواعد التقاطعات، ومشاة بأزياء تقليدية، وأطفال يلاحقون الكرة بفيزياء.
- السيارات تعود تلقائيًا إلى المواقف بعد نزولكم منها.

## الاختبار قبل أي تعديل
1. شغّل مجلد المشروع محليًا: `py -m http.server 8123`
2. افتح `http://127.0.0.1:8123/tests.html` ويجب أن ترى **36 ناجح / 0 فاشل**.
3. بعد ذلك افتح `index.html` ولعبًا طبيعيًا.

## النشر على GitHub Pages
1. ارفع الملفات كلها: `index.html` و `tests.html` و `.nojekyll` و `README.md` و مجلد `js/`.
2. Settings ← Pages ← Source: `Deploy from a branch` ← Branch: `main` / `(root)` ← Save.
3. بعد دقيقة يظهر الرابط: `https://USERNAME.github.io/REPO/`
   (المستودع الحالي: <https://youef.github.io/gamesplay/>)
