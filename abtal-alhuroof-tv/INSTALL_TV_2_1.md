# أكاديمية الأبطال — إصدار التثبيت الآمن 2.1

## سبب النسخة المستقلة

ملفات APK السابقة من أكاديمية الأبطال كانت بنفس معرف الحزمة لكن بتواقيع Debug مختلفة، لذا يمكن أن يفشل التثبيت فوق نسخة موجودة برسالة عن فشل تثبيت الحزمة. هذا الإصدار يستخدم معرفًا منفصلًا **sa.youef.abtalacademy.tv**، لكي يتثبت جنبًا إلى جنب مع النسخ السابقة ولا يتعارض معها.

- نظام التشغيل الأدنى: Android 4.4 / API 19.
- البنية: APK واحد لا يحتوي مكتبات native؛ يعمل من ناحية المعمارية على ARMv7 وARM64 وx86 وx86_64.
- التوقيع: Android V1 وV2.
- الواجهة: ريموت DPAD وأسهم وOK والعودة، والعب دون إنترنت.
- **النسخة موقّعة بتوقيع تطويري، وليس بتوقيع نشر دائم**. لا تصلح الترقية المستقبلية بنسخة Debug من تشغيل بناء آخر إلا بتثبيت مفتاح توقيع دائم وآمن خارج المستودع.

## تثبيت بدون تعارض

1. انقل ملف APK المباشر (وليس ZIP) إلى فلاش USB أو بطاقة SD واستخدم مدير الملفات في الشاشة لفتحه.
2. تأكد من حجم الملف بعد النقل وأن الامتداد .apk وليس .zip أو .apk.zip.
3. فعّل تثبيت التطبيقات من مصادر غير معروفة للتطبيق الذي تستخدمه في فتح الملف.
4. ثبّت هذه النسخة **من دون إزالة تطبيق العز TV**، ولا يجب حذف نسخ الألعاب القديمة لأن المعرف هنا مختلف.
5. إذا ظهر فشل التثبيت مجددًا، تحقق من المساحة المتاحة وأرسل صورة الرسالة، أو نفذ `adb install -r filename.apk` من كمبيوتر متصل بالتلفزيون للحصول على كود الخطأ مثل `INSTALL_FAILED_OLDER_SDK` أو `INSTALL_FAILED_INSUFFICIENT_STORAGE`.

## تحقق آلي

GitHub Actions يفحص `aapt dump badging` وتوقيع V1/V2، ثم يثبت اللعبة مرتين على محاكي Android 4.4 ويفتحها ويضغط أزرار الريموت.
