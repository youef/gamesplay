# أكاديمية الأبطال TV — الإصدار 2.0.0

لعبة تأسيس للصف الأول الابتدائي تدعم **Android 4.4 (API 19)** مع 87 نشاطًا موزعة على ستة عوالم. ثلاث ألعاب صيد تفاعلية بالشبكة + لعبة ذاكرة + صناديق الهدايا + عشرات أنماط الأسئلة. جميع الأصول التعليمية محلية بلا إنترنت، ويُحفظ تقدم الطفل محليًا.

## التحكم بالريموت

- الأسهم الأربعة: التنقل بين جميع البطاقات والأزرار؛ التمرير التلقائي في قوائم الألعاب الطويلة.
- OK / Enter: تنفيذ اختيار البطاقة.
- زر الرجوع: العودة؛ زر القائمة (Menu): قائمة العوالم.
- أزرار 1-4: اختيار الإجابات مباشرةً في أسئلة الاختيار.
- تشغيل/إيقاف مؤقت أو Info: إعادة قراءة السؤال إذا كان التلفزيون يملك محرك تحويل نص لصوت.

## فحوص الجودة

**آليًا:** `node tests/quiz_sanity.cjs` — يفحص توليد آلاف الأسئلة، عدم تكرار الإجابات، وتوافق صياغة JavaScript مع البناء.

**GitHub Actions:** يبني APK عالميًا بدون مكتبات معمارية، ويتحقق من minSdk 19 وتوقيع V1+V2، ثم يختبر تثبيت التطبيق وفتحه بالريموت على محاكي Android 4.4.

## تنبيه مهم للتثبيت

الـ APK الحالي توقيع تطويري غير ثابت بين تشغيلات GitHub Actions. إذا كانت نسخة سابقة مثبتة بتوقيع مختلف، ينبغي إزالة النسخة القديمة قبل تثبيت الجديدة. قد يؤدي ذلك إلى فقدان التقدم المخزن محليًا. لضمان تحديثات مباشرة مستقبلًا يجب توفير مفتاح Release خاص وثابت في أسرار GitHub، وعدم رفع المفتاح الخاص إلى المستودع.

## المشروع

هذا المشروع مستقل داخل `youef/gamesplay` ولا يغير تطبيق العز TV. الصور الكرتونية ضمن الأصول المحلية؛ اللعب لا يجمع بيانات الطفل ولا يحتاج تسجيل دخول.
